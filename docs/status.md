# 当前状态

版本：**0.4.7**。计算基线：**1.0.1204**。发布记录以[GitHub Releases](https://github.com/yukixz/deepveinidle-buddy/releases)与[Greasy Fork](https://greasyfork.org/zh-CN/scripts/601896-deepveinidle-buddy)为准；历史变更见[更新说明](../CHANGELOG.md)。

## 功能范围

- 三模式：制造保留完整多订单与费用；收藏（制造）使用独立固定单，在执行计划升降目标或移除；收藏（采集）仅显示配方。首次默认制造，按角色恢复模式及三套筛选。
- 模式和材料／产物定价位于配方区之前，定价始终显示。材料新增“库存（仅仓库材料）”，按同品质仓库加背包筛选候选与批量加入，材料仍按卖单估值；已有订单及采购缺口保留。采集配方显示独立执行次数，不显示金币和金币／点列。
- 采购显示完整材料成本与抵扣后的采购成本，保留需求／库存／预计产物数字，不折叠。收藏固定单的执行计划标题行在自动移除右侧提供“删除所有计划”（确认后清空），自动移除文案缩短为“自动移除已完成”；目标操作顺序为＋、−、×。
- 角色、库存、收藏与任务只读同步；材料满足、当前动作和队列使用底色及边框。模式切换取消过期预填，旧控件不能编辑新模式。
- 双端共用规则；桌面拖动缩放，移动紧凑表格、冻结列及横滚；刷新默认关闭窗口，入口无自动提示。
- 工作区version=2保存订单、界面输入及可选collectionOrder／selectedMode；完整保留旧混合订单于制造模式。字段缺失与损坏分别处理，读取不自动写回，新增字段不支持旧版降级。角色与行情只存会话内存，串行保存及revision冲突保护保留。
- GitHub Actions验证与tag发布，仓库Webhook同步Greasy Fork；构建绑定版本、来源提交和摘要。统一入口见[发布日常入口](releasing.md#日常入口)。

## 验证与边界

本次调整：采集收藏自动展示全部采集方案，同来源相同期望执行次数合并，精通点和效率计入各品质贡献。移除品质筛选及主表稀有度、当前→目标；点击整行或按Enter／空格展开各品质进度、预计增加和精通点，执行按钮独立预填。保留其他筛选、单位和期望次数精度，旧品质筛选存档保留但不参与采集筛选。时间说明为“时间按直接丢弃采集物估算。”，中英文同步。具体规则见[面板设计](panel.md)。
