# 考虑自制半成品实施计划

依据[设计规格](../specs/2026-11-12-consider-crafting-intermediates-design.md)，在现有 JavaScript 计算模块中共用每次刷新内的比价结果，以同一报价支持配方预览和固定收藏单。

1. 在 crafting-estimates 与 metal-bars 比较同品质的可行路线，验证同价、单边与双边缺价、等级、库存和锁定。
2. 在 workspace 保留按订单顺序分配的库存以及配套制造数量，用其他预计产物抵扣替代购买缺口。用存在独立半成品收藏目标的订单验证。
3. 在 app 与 theme 中接入收藏候选估价、采购名称和按钮，购买草稿按实时路线核对。用两档价格核对候选、计划、按钮样式与实际预填。
4. 更新面板及存档说明，运行单测、构建和相关浏览器场景，比较同一输入下全量候选刷新与固定单重算的中位耗时。
